# Contrato RF-19

## ID

RF-19

## Objetivo

Asegurar la privacidad del acudiente y la entrega de alertas sin exposición cruzada de datos familiares.

## Alcance

- Notificaciones, accesos familiares y privacidad.
- Aislamiento de datos por estudiante/acudiente.

## Excluye

- Cambios en políticas de token o autenticación general.

## Criterios de aceptación

- El acudiente solo accede a los datos del estudiante que le corresponde.
- Las alertas se direccionan al receptor legal del estudiante.
- Los datos sensibles no se registran en logs.

## Denegaciones obligatorias

- [ ] Consulta de estudiante ajeno.
- [ ] Exposición de datos sensibles en logs.
- [ ] Fallo de RLS en notificaciones.

## Archivos permitidos

- `db/**`
- `docs/**`
- pruebas SQL

## Riesgos

- IDOR y fuga de información.
- Exposición de datos en tiempo real.

## Definición de terminado

- Pruebas de RLS y auditoría de registros en logs.
- Evidencia de aislamiento y trazabilidad del requisito.
