# Contrato RF-03

## ID

RF-03

## Objetivo

Control de descenso con validación de receptor autorizado, protocolo de retorno y registro de entrega.

## Alcance

- Descenso seguro.
- Verificación de autorización y resolución judicial.
- Registro de entrega y asistencia.

## Excluye

- Reglas de billing.
- Cambios no relacionados con custodia.

## Criterios de aceptación

- El descenso verifica que el estudiante está `A_BORDO_VEHICULO`.
- El receptor autorizado o acudiente cumple validación y bloqueo judicial.
- Se registra el estado de custodia y la entrega con evidencia.

## Denegaciones obligatorias

- [ ] `DENEGADO_NO_A_BORDO`.
- [ ] `DENEGADO_AUTORIZADO_INVALIDO`.
- [ ] `ALERTA_JUDICIAL_BLOQUEANTE`.

## Archivos permitidos

- `db/**`
- `docs/**`
- pruebas SQL

## Riesgos

- Pérdida de custodia.
- Bypass de validación de autorizados.

## Definición de terminado

- Casos SQL de descenso seguro y denegado.
- Evidencia del bloqueo judicial y del historial en cadena.
