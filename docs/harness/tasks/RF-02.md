# Contrato RF-02

## ID

RF-02

## Objetivo

Control de abordaje seguro y aforo atómico con validación de estudiante, viaje y capacidad nominal.

## Alcance

- Abordaje seguro.
- Validación de `DENEGADO_SOBRECUPO`.
- Registro de asistencia.

## Excluye

- Cambios en contratos frontend.
- Cambios en facturación o billing.

## Criterios de aceptación

- La función de abordaje valida el tipo de viaje y el estado del menor.
- El contador de aforo usa bloqueo atómico y deniega al sobrecupo.
- Se registra el historial de custodia y la asistencia con UUIDv7.

## Denegaciones obligatorias

- [ ] Abordaje fuera de `EN_CASA_ESPERA`.
- [ ] `DENEGADO_SOBRECUPO` cuando la capacidad se alcanza.
- [ ] Abordaje de pasajero no matriculado.

## Archivos permitidos

- `db/**`
- `docs/harness/**`
- pruebas SQL asociadas

## Riesgos

- Sobrecupo concurrente.
- Validación lógica incorrecta del recorrido.

## Definición de terminado

- Suite SQL que captura las denegaciones.
- Verificación del integridad del conteo y del historial.
