# Contrato RF-15

## ID

RF-15

## Objetivo

Aislar el flujo de mora, cartera y facturación del dominio logístico.

## Alcance

- `billing` aislado.
- permisos por rol.
- acceso al dominio de abordaje sin carga financiera.

## Excluye

- Cambios en rutas, vehículos o ruta del estudiante.

## Criterios de aceptación

- `app_user_operations` no tiene acceso a `billing`.
- El flujo de abordaje no expone datos de cartera.
- Facturación y cartera quedan solo para `app_user_billing`.

## Denegaciones obligatorias

- [ ] Intento de acceso a `billing` desde `app_user_operations`.
- [ ] Exposición de mora en la API de abordaje.

## Archivos permitidos

- `db/**`
- tests SQL
- docs/harness

## Riesgos

- Fuga de información financiera.
- Escalamiento de permisos en operaciones logísticas.

## Definición de terminado

- Validación por permisos SQL y auditoría de acceso.
- Pruebas de no ejecución para roles no autorizados.
