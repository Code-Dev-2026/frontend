# Contrato RF-06

## ID

RF-06

## Objetivo

Validación de adultos autorizados y control del patrón de entrega frente a restricciones judiciales.

## Alcance

- Adultos autorizados y límites por estudiante.
- Entrega a receptor legítimo.
- Restricciones de alerta judicial.

## Excluye

- Cambios de rutas o motores de GPS.

## Criterios de aceptación

- Máximo 3 autorizados por estudiante.
- La entrega a autorizado debe requerir una validación vigente.
- El bloqueo judicial debe impedir la entrega a un individuo con medida restrictiva.

## Denegaciones obligatorias

- [ ] Autorizado vencido o inactivo.
- [ ] Adulto no autorizado.
- [ ] Receptor con `alerta_judicial` activa.

## Archivos permitidos

- `db/**`
- `docs/**`
- pruebas SQL

## Riesgos

- Entrega no autorizada.
- Bypass de restricciones judiciales.

## Definición de terminado

- Pruebas SQL de denegación y de entrega permitida.
- Evidencia de la regla de seguridad y la trazabilidad.
